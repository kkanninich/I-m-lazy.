# Community Roadmap

This roadmap describes the intended growth of the community. It is a direction, not a delivery promise or a formal development-team plan.

## Foundation — completed

- [x] Establish the community repository and its purpose.
- [x] Publish the community guidelines.
- [x] Publish contribution guidance.
- [x] Add structured templates for reports and community submissions.

## Community launch — in progress

- [x] Enable GitHub Discussions.
- [x] Publish the first welcome announcement.
- [x] Create focused categories for Unlimited Gameplay, Mods and Tools, Private Environments, Guides and Tutorials, and Questions and Support.
- [ ] Invite members to introduce themselves and share what they want from the community.
- [ ] Collect the first set of guides, tools, and frequently asked questions.

## Knowledge base — planned

- [ ] Build an organized index of trusted tools and references.
- [ ] Add version and compatibility notes to shared resources.
- [ ] Create beginner-friendly setup and troubleshooting guides.
- [ ] Develop a searchable FAQ from recurring questions.

## Community projects — planned

- [ ] Let members propose experiments and community projects.
- [ ] Share demonstrations and progress updates.
- [ ] Encourage collaboration without requiring formal team membership.
- [ ] Review community priorities based on member interest.

## Principles

- Player participation comes before project size.
- Share verified information and label experiments clearly.
- Preserve attribution and respect intellectual property.
- Keep activity lawful, consensual, and limited to authorized environments.
