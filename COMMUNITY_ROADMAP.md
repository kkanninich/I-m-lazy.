# Community Roadmap

This roadmap describes the intended growth of the community. It is a direction, not a delivery promise or a formal development-team plan.

## Foundation — completed

- [x] Establish the community repository and its purpose.
- [x] Publish the Community Guidelines and contribution guidance.
- [x] Add structured templates for bug reports, tool submissions, guides, and project ideas.
- [x] Enable GitHub Discussions and publish the first welcome announcement.
- [x] Create focused categories for gameplay, tools, private environments, guides, and Q&A.

## Knowledge base — in progress

- [x] Publish a resource directory structure with version, platform, verification, and limitation fields.
- [x] Publish a starter FAQ and support guidance.
- [ ] Collect and review the first community-submitted resources.
- [ ] Publish practical, step-by-step setup and troubleshooting guides.
- [ ] Build a searchable reference library from verified community contributions.

## Community participation — in progress

- [x] Provide an open project proposal form; no formal team membership is required.
- [ ] Invite members to introduce themselves and share what they want from the community.
- [ ] Gather the first proposals and identify people interested in contributing.
- [ ] Share demonstrations, progress updates, and member showcases.
- [ ] Review community priorities based on member interest.

## Principles

- Player participation comes before project size.
- Contributions can be non-code: testing, documentation, translation, feedback, research, and design all matter.
- Share verified information and label experiments clearly.
- Preserve attribution and respect intellectual property.
- Keep activity lawful, consensual, and limited to authorized environments.
