# Support and Help

This repository is a community hub, not an official game support channel. For account, purchase, or service issues, use the game's official support channels.

## Choose the right place

| Need | Where to go |
|---|---|
| Ask a gameplay or setup question | [Questions and Support (Q&A)](https://github.com/kkanninich/I-m-lazy./discussions/categories/questions-and-support) |
| Start an open conversation | [General Discussions](https://github.com/kkanninich/I-m-lazy./discussions/categories/general) |
| Share a guide | [Guides and Tutorials](https://github.com/kkanninich/I-m-lazy./discussions/categories/guides-and-tutorials) |
| Report a reproducible bug | [Bug or compatibility issue form](https://github.com/kkanninich/I-m-lazy./issues/new?template=bug_report.yml) |
| Submit a tool or modification | [Tool submission form](https://github.com/kkanninich/I-m-lazy./issues/new?template=tool_submission.yml) |
| Correct the resource index | [Resource Directory](RESOURCE_DIRECTORY.md) and GitHub Issues |

## Help request checklist

When asking for help, include:

1. Game, tool, and platform versions.
2. What you were trying to do.
3. What happened and what you expected.
4. Steps to reproduce the issue.
5. Error messages with private information removed.
6. Whether the result is repeatable or happened only once.

Do not share passwords, session cookies, access tokens, account identifiers, payment details, or private data. Screenshots should be checked for personal information before posting.

## Keep it responsible

Ask for help only with accounts, software, and environments you own or are authorized to use. The community cannot help with account theft, unauthorized access, service disruption, or redistribution of protected game content.
