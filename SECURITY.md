# Security Policy

This repository is primarily a community knowledge hub. Security reports should be limited to issues affecting this repository, its community resources, or a tool maintained here.

## Do not publish secrets

Never include passwords, access tokens, session cookies, private keys, personal data, or another person's account information in an issue, discussion, pull request, or screenshot.

## Reporting a security concern

Do not publish details of a suspected vulnerability or expose someone else's private information in a public discussion. Use GitHub's private vulnerability reporting or security advisory contact option for this repository if it is available. If that option is not available, contact the repository owner through GitHub privately with a concise description and steps to reproduce in an environment you own or are authorized to test.

Do not attach credentials, private user data, proprietary game files, or unrelated system information.

## Scope and limitations

- Do not test against official game services, other players' accounts, or systems you do not own or have explicit permission to test.
- Do not attempt denial of service, credential harvesting, persistence, or unauthorized access.
- A report does not grant permission to continue testing.
- This community does not promise a response time or a formal security-response service.

## Maintainer handling

Maintainers should validate reports carefully, limit access to sensitive information, and avoid publishing details that could expose users or systems. Any public summary should be coordinated with the reporter when practical.
