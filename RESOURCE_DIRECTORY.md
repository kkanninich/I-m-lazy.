# Community Resource Directory

This is the community index for tools, guides, research, compatibility notes, and other resources shared by members.

**No resource is endorsed just because it appears here.** Verify the original source, permissions, safety, and compatibility before using anything. Entries should link to the author's original page whenever possible. Do not upload proprietary game files, paid assets, credentials, or unauthorized copies.

## How to read verification status

| Status | Meaning |
|---|---|
| Verified | A contributor tested the resource and supplied reproducible details for the stated version and environment. |
| Partially tested | Some functions or configurations were tested; limitations must be listed. |
| Experimental | Research or a proof of concept; not confirmed as reliable. |
| Archived | No longer maintained or known to be incompatible with current versions. |
| Needs review | Submitted by a member but not yet checked by maintainers or other contributors. |

Verification is always scoped to the versions and environment stated by the contributor. It is not a guarantee that a resource is safe or works for everyone.

## Submission checklist

Before adding a resource, provide:

- Exact resource name and original author's page.
- What it does and what it does not do.
- Supported game, tool, and platform versions.
- Dependencies and installation prerequisites.
- Test environment and reproducible test steps.
- Known limitations, risks, and whether it is maintained.
- Permission to share any included material.

## Report an issue

Use [GitHub Issues](https://github.com/kkanninich/I-m-lazy./issues/new/choose) for corrections, broken links, compatibility reports, and resource submissions. Keep account data, passwords, session cookies, and access tokens out of every report.

See [Community Guidelines](COMMUNITY_GUIDELINES.md) before contributing.
