# Contributing

Thanks for helping the community grow. Contributions do not need to be code.

## Ways to contribute

- Write or improve a beginner guide.
- Share troubleshooting steps or compatibility notes.
- Document a tool or research project.
- Translate useful documentation.
- Report broken links or outdated information.
- Share a project showcase with screenshots and a clear description.
- Help answer questions respectfully.

## Before submitting

1. Read [Community Guidelines](COMMUNITY_GUIDELINES.md).
2. Search existing files and discussions to avoid duplicates.
3. Use clear titles and explain the context.
4. Separate confirmed results from guesses or experiments.
5. Remove passwords, tokens, private data, and other sensitive information.
6. Confirm that you have permission to share any files or assets you attach.

## Suggested format for technical posts

- **Topic:**
- **Game version / platform:**
- **Tool or project version:**
- **Goal:**
- **Steps or method:**
- **Observed result:**
- **Known limitations / risks:**
- **Sources and credits:**

## Pull requests

Keep changes focused. Explain what changed and why, link related discussions when available, and avoid including proprietary game files or unrelated generated binaries.

You are welcome to participate even if you have never made a pull request.
